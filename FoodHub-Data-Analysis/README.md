# FoodHub: Order Data Analysis

**MIT Applied Data Science — Foundations Project**

---

## Overview

FoodHub is a food delivery platform operating in New York City. This project
performs end-to-end exploratory data analysis on the platform's order dataset
to surface insights on order patterns, delivery performance, customer behavior,
and cuisine demand.

---

## Business Problem

FoodHub wants to understand which factors drive customer satisfaction and where
operational improvements can be made. The analysis identifies patterns in order
volume, delivery times, cuisine preferences, and cost behavior to support
data-driven decisions across operations and marketing.

---

## Approach

| Phase | Details |
|-------|---------|
| Data Understanding | Order-level dataset, delivery and rating features |
| Univariate Analysis | Distributions of order value, delivery time, ratings |
| Bivariate Analysis | Relationships between cost, time, cuisine, and satisfaction |
| Business Insights | Actionable findings for operations and marketing |
